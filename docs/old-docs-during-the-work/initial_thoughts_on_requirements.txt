Консольное приложение по поиску документов с наличием заданной строки(подстроки, substring) в указанной  директории файлов формата .docx, .pdf 

find_in_doc <dir_to_search_through> <search_str> <workers_count>

Реализовать:
- взаимодействие через консоль, команда - find_in_doc
- передача параметров(и, соответственно, парсинг в программе) 
- прогулка по файловой системе, начиная с директории, указанной в параметрах(аргументах)
- многопоточность и указание количества выделяемых потоков(раст-рутинов(ко-рутины, го-рутины)) в параметрах

- чтение текста с файлов .pdf, .docx, механизмы OCR, оцифровки документов
- поиск вхождений строки в файл
- определение позиции подстроки: страница, абзац, предложение, слово

- поочерёдный вывод найденных файлов 
- формирование массива файлов с указанием пути всех файлов, в которых есть вхождение, substring
- формат вывода:

result: 
<Array
  count_found_files,
  formats_found<Array<String>>,
  found_files_paths<Array<Found_file>>
>

Found_file:
  filename,
  filepath,
  matches<Array<Match>>

Match:
  page_no,
  paragraph _on_page | _on_whole_file, ? | line
  word

- представление результатов в различных форматах: .csv, ...
